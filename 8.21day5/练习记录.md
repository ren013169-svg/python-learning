# day5 练习记录(命令:说明)
1. pwd:查看当前路径
2. ls :查看当前目录所有文件或者文件夹
ls -a: 查看隐藏文件 ls -l :查看文件详细信息
3. cd :去别的地方，加绝对路径或者相对路径
4. mkdir :建立文件夹
5. touch :建立文件
6. cp:复制一个文件并且重新命名，也可以转移到其他地方
7. mv: 移动文件或文件夹 或者重新命名
8. rm : 删除文件
9. echo: 输出 echo > :把内容输出写进文件并且覆盖原有
echo >> : 把输出写进文件最后一行
10. cat : 查询文件的全部内容
11. head:从头查询前面的内容
12. tail: 从尾查询后面的内容
13. grep:搜索带有特定内容的行
14. wc:数有多少行
15. -r : 文件夹的移动删除必须带着
16. . :表示全部
17. |：表示把前面的输出输入后面
18. git status:查看哪些文件有变化
19. git log --oneline: 查看历史提交
20. git diff:看具体改了什么内容
21. git pull:从GitHub获取最新的改动内容
22. git add:将文件从工作区送到暂存区
23. git commit -m:把文件从暂存区送到本地仓库
24. git push :将本地仓库上传到GitHub
# 我踩的坑
1. cd 后面的地址必须是/不能是\
2. touch建立的文件要自己写后缀
3. 文件夹的移动和删除必须带着-r
4. head 和tail查询必须带-
5. 每次提交前都跑git status 和git diff 观察输出，提交后看git -oneline看提交记录确认提交成功
